# Лабораторная работа №2. Алгоритмы и абстрактные структуры данных

## Описание

Изучение алгоритмов работы с абстрактными структурами данными.
Решение индивидуальных задач на языке **C++, Go**.
Все программы обязательно должны быть основаны на структурах,
реализованных в лабораторной работе №1.

Сложность: 4/10
Темы: Структуры данных, Алгоритмы, Big O нотация

## Задание
Задания охватывают следующие темы:

1. **Стек** — вычисление арифметических/логических выражений,
   преобразование инфиксной нотации в постфиксную, обратная польская
   запись, проверка порядка выполнения задач, обход деревьев и графов
   в глубину (DFS), проверка корректности XML, астероиды, бейсбольная
   игра, строка со скобками.
2. **АТД Множество** — добавление, удаление, проверка наличия элемента.
   Все операции — за O(1). Запуск:
   `./<программа> --file <файл> --query <запрос>`.
3. **Множество** — задачи на подмножества, инопланетный геном, черепахи.
   Все задачи выполняются с использованием множества из задания 2.
4. **Массив** — различные подмассивы, поиск суммы, сопоставление
   с паттерном, пирамида из блоков, контрольная по ударениям, гистограмма.
5. **Двоичное дерево** — правый край дерева, чтение змейкой,
   АВЛ-сбалансированность, вывод развилок, проверка дерева, вывод листьев,
   высота дерева, глубина добавляемых элементов, алгоритм Хаффмана.
6. **Хеш-таблица** — разрешение коллизий (линейное апробирование,
   двойное хеширование, метод цепочек, хеширование кукушки),
   метод свёртки, реструктуризация, римские цифры, оптимизация
   маршрутов, количество сотрудников, изоморфные строки, самая длинная
   подстрока, фильтр Блума, родословная.
7. **LRU/LFU** — кэш с вытеснением давно не использовавшихся (LRU)
   или реже всего использовавшихся (LFU) элементов.
